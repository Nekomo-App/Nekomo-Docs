# Sources and extensions

Nekomo uses external sources and extension ecosystems. Sources are independently maintained and can change without Nekomo releases.

## General guidance

1. Find the source through its official developer or project channel.
2. Confirm its ecosystem, version requirements, and compatibility with your Nekomo build.
3. Review permissions and publisher information.
4. Follow the source's own installation and update instructions.
5. Test it and report reproducible issues with version details.

Nekomo does not host or bundle third-party extension packages. Avoid unofficial repackaged files and never share login credentials, session cookies, or API tokens in support requests.

For format-specific information and compatibility reports, see [Nekomo Extensions](https://github.com/Nekomo-App/Nekomo-Extensions).
