# Features overview

Available features depend on the installed app version and device. Nekomo's feature areas may include:

- Anime and manga discovery through supported catalogues.
- User-added external sources for content access.
- Anime playback and manga reading workflows where supported by the selected source.
- Catalogue metadata such as titles, descriptions, posters, and artwork.
- Tracking integrations such as AniList, MyAnimeList, or Kitsu where supported.
- Android phone and Android TV-oriented usability.

This is a high-level overview, not a guarantee that every feature is available in every build. Consult current release notes and in-app settings for version-specific details.
