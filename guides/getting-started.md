# Getting started

## 1. Get Nekomo

Use the official Nekomo project pages and repositories to find current project information and releases. Verify that downloads come from an official project-controlled location.

## 2. Set up the app

Open Nekomo, review the available settings, and configure catalogue, tracking, and source preferences as needed. Exact screens may differ between versions.

## 3. Add sources

Nekomo relies on user-added external sources. Follow the source developer's instructions and the [sources and extensions guide](sources-and-extensions.md). Review permissions and source provenance before installing anything.

## 4. Browse and track

Use the available catalogue and metadata features to discover titles. Where supported, connect a tracking provider through the app's own settings.

## 5. Get help

If something does not work, check the [FAQ](../FAQ.md) and [troubleshooting guide](troubleshooting.md) before opening an issue.
