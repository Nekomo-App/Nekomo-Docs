# Getting started

## 1. Get Nekomo
Use official Nekomo project pages and repositories to find current project information and releases. Verify downloads come from an official project-controlled location.

## 2. Set up the app
Open Nekomo, review available settings, and configure catalogue, tracking, and source preferences as needed. Screens may differ between versions.

## 3. Add sources
Nekomo relies on user-added external sources. Follow the source developer's instructions and the [sources and extensions guide](sources-and-extensions.md). Review permissions and source provenance first.

## 4. Browse and track
Use available catalogue and metadata features to discover titles. Where supported, connect a tracking provider through the app's settings.

## 5. Get help
Check the [FAQ](../FAQ.md) and [troubleshooting guide](troubleshooting.md) before opening an issue.

## Which build should I download?

| Channel | Phone app | Android TV app |
|---|---|---|
| Stable | `Nekomo-phone-release.apk` (`app.nekomo`) | `Nekomo-TV-release.apk` (`app.nekomo.tv`) |
| Beta | `Nekomo-phone-beta.apk` (`app.nekomo.beta`) | `Nekomo-TV-beta.apk` (`app.nekomo.tv.beta`) |
| Alpha (debug) | `Nekomo-phone-alpha.apk` (`app.nekomo.debug`) | `Nekomo-TV-alpha.apk` (`app.nekomo.tv.debug`) |

Every Android TV build has **TV** in its app name and file name. Channels install side by side because they use different package names. Requires Android 7.0 or newer. The TV APKs can also be installed on a phone for testing.
