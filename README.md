# Nekomo Documentation

Official documentation for the Nekomo app and its community ecosystem.

Nekomo is a community-driven client for discovering and accessing anime and manga through user-added sources and supported integrations. Features and compatibility may vary by app version, device, and upstream providers.

## Important notes

Nekomo does not bundle or host third-party sources or extensions. Users choose and add external sources themselves. Third-party services and extensions are independently maintained and may change or stop working without notice.

This documentation is a community resource and may not describe every feature in every release. Always check the app version and release notes relevant to your installation.
