# Security and privacy guidance

Use official Nekomo project channels and review external source provenance before installing extensions.

- Treat third-party sources and responses as untrusted.
- Review requested permissions.
- Keep the app and device updated.
- Do not post passwords, tokens, cookies, or private account data in public issues.
- Share security vulnerabilities privately with the project maintainers through an official contact channel if one is published.

This documentation does not certify third-party sources as safe. External services have their own privacy policies and terms.
