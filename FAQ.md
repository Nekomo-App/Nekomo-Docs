# Frequently asked questions

## What is Nekomo?

Nekomo is a community-driven anime and manga client that brings supported catalogues, user-added sources, and viewing or reading features into one app.

## Does Nekomo include sources?

No. Nekomo does not bundle third-party sources or extension packages. Users add sources separately and should only use sources they trust.

## Why is a source missing or not working?

External sources are maintained independently. They can become unavailable or incompatible after upstream changes. Check the source's official release information and the [troubleshooting guide](guides/troubleshooting.md).

## Why are titles, posters, or descriptions missing?

Metadata and content sources are separate systems. Check the selected catalogue or metadata provider, search using an alternate title, and make sure the app is updated.

## Does every extension format work?

No. Compatibility depends on the format, extension version, Nekomo version, Android version, and upstream APIs. See the [Nekomo Extensions compatibility notes](https://github.com/Nekomo-App/Nekomo-Extensions).

## Where can I report a bug?

Use the issue tracker in the [main Nekomo repository](https://github.com/Nekomo-App/Nekomo/issues). Include app version, Android version, reproduction steps, and relevant logs with personal information and secrets removed.
