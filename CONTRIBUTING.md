# Contributing to Nekomo Docs

Documentation improvements are welcome.

## Guidelines

- Use clear, concise language.
- Prefer task-based instructions with numbered steps.
- State which app version or platform a feature applies to when known.
- Do not invent features, settings, or compatibility guarantees.
- Link to official upstream documentation where appropriate.
- Never include passwords, access tokens, session cookies, or private user information.

## Suggested changes

Bug fixes, clearer setup steps, troubleshooting notes, accessibility improvements, and developer documentation are all useful.

For app bugs or feature requests, use the issue tracker in the main Nekomo repository.
