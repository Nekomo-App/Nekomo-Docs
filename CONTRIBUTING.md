# Contributing to Nekomo Docs

Documentation improvements are welcome.

- Use clear, concise language and task-based steps.
- Mention app versions or platforms when known.
- Do not invent features, settings, or compatibility guarantees.
- Link to official upstream documentation where appropriate.
- Never include passwords, access tokens, session cookies, or private user data.

Useful contributions include setup instructions, troubleshooting notes, accessibility improvements, and developer documentation. For app bugs or feature requests, use the main Nekomo repository's issue tracker.
